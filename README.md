# SubPlayer – German movie -> English AI subtitles (free)

1. Open this folder in Android Studio (Ladybug or newer). Let Gradle sync.
2. Free API key: https://console.groq.com -> API Keys (no card needed).
3. Run on your phone (USB debugging) or Build > Build APK.
4. Open a video -> tap the CC icon (top right) -> paste key -> wait for subtitles.
   The .srt is saved on the phone; later playback needs no internet.

Gestures: hold = 2x, double tap left/right = -10s/+10s, tap = show/hide controls.
